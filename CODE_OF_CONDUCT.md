# Code of Conduct

Fouroam Server welcomes contributors with different backgrounds and experience levels. We expect respectful and constructive collaboration.

## Expected behavior

- Treat others with courtesy, patience and respect.
- Offer practical feedback and discuss technical ideas rather than attacking people.
- Respect intellectual property, privacy and applicable laws.
- Make room for newcomers and different perspectives.

## Unacceptable behavior

- Harassment, discrimination, personal threats or insults.
- Unwanted sexual attention or sexual harassment.
- Publishing another person's private information without permission.
- Spam, trolling or intentionally disruptive behavior.
- Encouraging piracy, stolen credentials or security bypasses.

## Scope and enforcement

These standards apply in project-maintained GitHub issues, discussions, pull requests and other official communication spaces. Maintainers may remove comments or submissions, issue warnings or restrict participation when necessary.

## Private reports

Report conduct concerns privately to **athiliorecovery@gmail.com** with the subject `Fouroam Server conduct report`. Please do not publish personal or sensitive details in public issues.
